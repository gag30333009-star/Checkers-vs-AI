# ♟️ Russian Checkers vs AI

A browser-based Russian checkers game where you can play against an AI opponent.

## 🎮 Features

- Russian checkers rules
- AI opponent with 4 difficulty levels
- Beginner, Normal, Hard and Impossible modes
- Mandatory captures
- Kings can move long distances
- Draw after 15 moves without a capture

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
